# python-data-automation
Скрипты на Python и NumPy для автоматизации расчетов и обработки массивов данных.

# Python Data Automation & NumPy Processing

## 📌 Описание проекта (Description)
В данном репозитории собраны лабораторные работы и скрипты, написанные на Python для автоматизации математических вычислений и обработки данных. Проект демонстрирует навыки работы с многомерными массивами и базовыми алгоритмами автоматизации.

## 🛠 Технологии и инструменты (Technologies)
* **Язык:** Python 3
* **Библиотеки:** NumPy
* **Ключевые концепции:** List comprehensions, lambda-функции, обработка исключений (try-except), работа с файловой системой.

## ⚙️ Что реализовано (Features)
* Чтение и запись данных из файлов.
* Обработка и фильтрация данных с использованием генераторов списков и анонимных функций.
* Работа с матрицами и массивами через `numpy`: создание (`numpy.array`), изменение размерности (`shape`, `reshape`) и извлечение срезов (`slicing`).
* Базовая защита кода от ошибок ввода (обработка исключений).

## 🚀 Как запустить (How to run)
1. Склонируйте репозиторий: `git clone https://github.com/Ваш_Логин/python-data-automation.git`
2. Установите зависимости: `pip install numpy`
3. Запустите нужный скрипт: `python script_name.py`

### 📂 Скрипт: `engine.py` (Моделирование сигнала мотора)
* **Цель:** Имитация работы реального датчика путем генерации чистого синусоидального сигнала и наложения на него нормально распределенного шума.
* **Используемые методы NumPy:** `np.linspace` для временного вектора, поэлементное применение `np.sin`, генерация шума через `np.random.normal` с использованием размерности массива (`shape`).
* **Визуализация:** Построение графиков исходного и зашумленного сигналов средствами `matplotlib.pyplot`.

* **update:**
* **Экспорт данных:** Объединение массивов через np.column_stack и сохранение сгенерированных временных рядов в файл CSV с помощью np.savetxt для последующего анализа.

### 📂 Скрипт: `sensor_mock.py` (Генератор данных датчика температуры)
* **Цель:** Имитация потока "сырых" данных с промышленного датчика (Mock-генератор) для отладки систем сбора данных.
* **Техническая реализация:** Генерация списка словарей `{'time', 'value', 'sensor_id'}`. Для имитации тепловой инерции физического объекта реализован алгоритм плавного случайного блуждания (random walk) с использованием модуля `random`.
* **Применение:** Подготовка датасетов для тестирования SQL-баз данных и скриптов аналитики.

### 📂 Скрипт: visualizer.py (Фильтрация и анализ логов мотора)
* **Цель:** Чтение "сырых" данных с датчика из лог-файла, алгоритмическое подавление высокочастотного шума и подготовка чистового инженерного графика для сравнения результатов.
* **Используемые методы NumPy:** Загрузка матрицы данных из CSV с помощью np.loadtxt, разделение двумерного массива на векторы (slicing), реализация цифрового фильтра скользящего среднего (Moving Average) через математическую свертку np.convolve.
* **Визуализация:** Наложение графиков на одни оси с настройкой прозрачности (alpha). Профессиональное оформление средствами matplotlib.pyplot (сетка, легенда, подписи с единицами измерения) и экспорт отчета в PNG с автоматическим кадрированием (bbox_inches='tight').
